🔑 GitHub Token

No token saved yet
Required for private Albertsons repos. Create one at GitHub → Settings → Developer settings → Personal access tokens with scopes: repo and read:org. Your token is stored locally in Chrome and never sent anywhere except the GitHub API.
How it works
Once saved, the token is used automatically — you never need to enter it again. The popup just shows a URL field. Click Analyze Run → and go.
⚙ Analyze RCA button on GitHub
When you open any GitHub Actions run page for ocom-api-automation, a blue ⚙ Analyze RCA button appears automatically. Click it — analysis opens in a new tab immediately, token used silently.

🔄 Extension Reload

After editing extension files (js, css, html), hard-reload the extension so Chrome picks up your changes. Equivalent to clicking the reload button on chrome://extensions.
